# Keyboard shortcuts

Trivium is designed to be driven from the keyboard. On **Windows**, use `Ctrl` where the table shows `⌘`, and `Alt` where it shows `⌥`.

## Modes and navigation

| Shortcut | Action |
|----------|--------|
| `⌘1` | Switch to **Code** mode |
| `⌘2` | Switch to **Research** mode |
| `⌘3` | Switch to **Write** mode |
| `⌘N` | New conversation |
| `⌘K` | Search all conversations, globally |
| `⌘\` | Collapse or expand the sidebar |
| `⌘,` | Open Settings |

## During a run

| Shortcut | Action |
|----------|--------|
| `↵` | Send — while a run is active, the message is **queued** |
| `⌥↵` | **Steer** the current run with the message instead of queuing it |
| `esc` | Stop the current run |
| `/` | Open the command palette (`tab` completes commands) |
| `esc` | Close any open dialog or popup |

:::tip[Queue, steer, stop]
The three input behaviors compose: queue a follow-up with `↵` while the agent is still working, redirect it mid-flight with `⌥↵`, or cut the run short with `esc`. The agent keeps working on queued messages in order.
:::

Switching modes never interrupts a run — sessions keep going in the background, and a badge in the sidebar shows which conversations are still active.
