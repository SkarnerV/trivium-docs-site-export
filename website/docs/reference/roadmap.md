# Roadmap

Trivium is in **early preview**. This page tracks what has shipped and what is actively being worked on.

## Shipped

- **Three modes** with real-time steps — Code, Research and Write, each a dedicated agent profile
- **Inline dialogs and notifications** — extension and agent prompts render as native UI
- **Changes panel** — baselines, diffs, keep / revert
- **Settings page** — per-mode models, permissions and extensions
- **Research notes panel** — note preview with a Sources tab
- **Write tracked changes** — accept or reject edits individually or all at once
- **Memory** — global, project and daily layers via `@pify/memory`
- **Usage** — token and cost statistics with a calendar heatmap
- **Connectors** — MCP server management, logins and `mcpServers` JSON import
- **Git view** — staged, unstaged, untracked and conflicted files
- **Message edit / fork / copy**

## In progress

- **Install extensions from npm by name**, plus first-party `@coresmos` plugins
- **Dark theme**
- **Signed builds** for all three platforms
- **Git snapshot tracking of bash changes** — capturing what commands change, not just what edits change

For the finer-grained picture, watch the [repository](https://github.com/SkarnerV/Trivium) and its issue tracker.
